# qdown - yt-dlp를 위한 심플한 GUI

qdown은 강력한 기능을 자랑하는 `yt-dlp` 커맨드라인 툴을 누구나 쉽게 사용할 수 있도록 만든 직관적인 그래픽 유저 인터페이스(GUI) 프로그램입니다. 복잡한 터미널 명령어 없이 유튜브 동영상을 원하는 화질로 손쉽게 다운로드하세요.

이제 qdown은 완전히 독립적인 데스크톱 애플리케이션(Electron 기반)으로 작동하며 브라우저나 복잡한 스크립트 없이 더 빠르고 쾌적하게 실행됩니다!

## 🚀 주요 기능 및 특징 (v1.1.0 업데이트)
- **32px 초슬림 커스텀 타이틀바**: 기본 OS의 투박한 타이틀바를 걷어내고, qDown의 세련된 디자인 아이덴티티를 살린 드래그 가능한 커스텀 타이틀바를 제공합니다.
- **설정 및 크레딧 통합 모달**: 복잡한 경로 표출을 제거하고 설정(톱니바퀴) 단일 아이콘으로 통합하였으며, 모달창 내부에서 다운로드 경로 변경, 라이브러리 크레딧 확인, 자체 삭제를 진행할 수 있습니다.
- **설정 영구 저장 및 자동 로드**: 화질 선택, 다운로드 타입, 파일 포맷(MP4/MKV/MP3 등), 음질 비트레이트, 자막 내장 옵션 및 아코디언 상태까지 사용자가 마지막으로 선택한 환경이 `localStorage`에 영구 기억됩니다.
- **앱 자체 안전 삭제 (Uninstall)**: 설치 버전(NSIS) 구동 시, 앱 내부에서 바로 언인스톨러(`Uninstall qDown.exe`)를 백그라운드로 안전하게 호출하고 프로그램을 종료시키는 자체 삭제 기능이 추가되었습니다.
- **이중 다운로드 및 파일 유실 문제 수정**: Electron 환경에 특화된 내부 로직을 통해 영상 다운로드 완료 시 브라우저에서 중복 스트림을 재발생시키지 않고 로컬 원본을 보존 및 3초 후 SSE 작업 메모리를 완벽히 해제하도록 수정했습니다.

## 📥 설치 및 사용 방법

쉽고 편리한 설치형(Installer) 패키지로 동작합니다!

### Windows 사용자
1. **[Releases](../../releases)** 페이지로 이동합니다.
2. `qDown Setup 1.1.0.exe` (또는 최신 버전) 설치 프로그램을 다운로드하고 실행합니다.
3. 설치 마법사의 안내에 따라 설치 경로를 지정하고 설치를 완료합니다.
4. 바탕화면 또는 시작 메뉴의 바로가기 아이콘을 더블 클릭하여 실행합니다.
   *(참고: 윈도우 디펜더 경고창이 뜰 경우 '추가 정보'를 누른 후 '실행'을 클릭해 주세요.)*

### macOS 사용자 (추후 지원 예정)
현재 릴리스는 Windows 환경에 최적화되어 있습니다. macOS용 릴리스 패키징은 향후 추가될 예정입니다. 소스코드를 다운로드 받아 직접 실행하실 수 있습니다.

## 🛠️ 개발자용 가이드 (직접 빌드하기)

코드를 수정하거나 실행 파일을 직접 빌드하고 싶다면 아래 과정을 따라주세요:

### 요구 사항
- [Node.js](https://nodejs.org/) (v18 이상 권장)

### 1. 코드 다운로드 및 패키지 설치
```bash
git clone https://github.com/qpi-labels/qdown.git
cd qdown
npm install
```

### 2. 개발 모드로 실행
프론트엔드(Vite)와 백엔드(Express) 그리고 데스크톱 앱(Electron)을 동시에 개발 모드로 띄웁니다:
```bash
npm run dev:electron
```
(브라우저에서만 빠르게 UI 테스트를 하고 싶다면 `npm run dev`를 입력하세요.)

### 3. 설치형 앱 릴리즈 패키지 생성
소스 코드를 빌드하고 다른 사람에게 배포할 수 있는 설치용 `.exe` 파일을 생성하려면 아래 명령어를 입력하세요:
```bash
npm run build:app
```
이 명령어는 자동으로 다음 작업들을 수행합니다:
1. 프론트엔드 빌드 (`dist` 폴더 생성)
2. 백엔드 서버 완벽 번들링 (`dist-server/server.cjs` 생성)
3. `electron-builder`를 사용하여 `release-app` 폴더 내부에 설치용 파일인 `qDown Setup 버전.exe` 파일 생성
